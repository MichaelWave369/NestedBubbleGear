# Bubble Atlas

The word **bubble** in NBG is an abstraction, not a claim that every modeled domain is literally spherical.

A bubble is a bounded or conditionally bounded state domain with an interface through which state, flux, symbols, or constraints may pass.

## Canonical bubble families

### 1. Nested Bubble

A domain inside another domain.

```text
B0
└── B1
    └── B2
```

Primary questions:
- What state is visible at each nesting level?
- Which distinctions survive projection outward?
- Can ancestry be reconstructed from downstream residue?

### 2. Boundary Bubble

A domain whose interface is itself dynamically meaningful.

State sketch:

[
B=(X,Sigma)
]

where `X` is internal state and `Σ` is boundary/interface state.

Primary questions:
- Does the interface encode or erase state?
- Can interface orientation/polarity change transport?
- Can the boundary evolve with the flux crossing it?

### 3. Gear Bubble

A bubble participating in recurrent transport or cycle-space current.

A Gear can be viewed as:
- nonzero cycle current `J` with zero net accumulation;
- an ordered cycle transformation `Mγ`.

Primary question:
- What survives repeated traversal when the visible state appears stationary?

### 4. Keyhole Bubble

A domain observed only through a restricted projection:

[
O=P(X).
]

Primary question:
- Which full-state distinctions are collapsed by the current observer?

### 5. Altermath Bubble

A domain whose coarse description reports cancellation while causally relevant internal structure remains.

Working witness:

[
P(X)=P(X')
]

but there exists an allowed future operation `w` such that

[
P(ho(w)X)
eq P(ho(w)X').
]

### 6. Dynamic / Flux Bubble

A domain maintained by persistent throughput.

A steady state may satisfy

[
dot X=0
]

while

[
J
eq0.
]

Primary question:
- Is the system static, or dynamically maintained?

### 7. Symbolic / Conveyor Bubble

A domain that emits or receives a transport representation distinct from its internal state.

[
X_i
ightarrow
Z_{ij}
ightarrow
X_j.
]

The conveyor state `Zij` may carry:
- symbol/payload;
- frame;
- polarity;
- hidden residue;
- flux;
- timing;
- provenance.

### 8. Experimental Bubble

A deliberately small finite model designed to isolate one claim.

Examples:
- AH2: latent residue;
- AH3: boundary transfer;
- AH5: path order;
- AH6: loop residue;
- AH8: neighboring plaquettes.

### 9. Speculative Physical Bubble

A possible application to real physics or cosmology.

Examples may include causal horizons or nested cosmological domains.

These are **speculative mappings** unless a separate physical model, parameter mapping, and empirical test justify them.

## Cross-cutting coordinates

A richer bubble can be represented schematically as

[
B=(X,Sigma,J,M,P,R)
]

where:

- `X` — domain state;
- `Σ` — interface state/geometry;
- `J` — flux/current;
- `M` — active transport/transformation;
- `P` — observer keyhole;
- `R` — retained residue/provenance.

The Bubble Atlas is intended as a navigation aid, not a declaration that every model must instantiate every coordinate.
