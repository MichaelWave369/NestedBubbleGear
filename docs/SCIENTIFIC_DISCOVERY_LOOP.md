# NBG Scientific Discovery Loop · PR #104

## Purpose

Make the NBG Spiral Gear → Phase & Closure → Adaptive Phase Keyhole →
Unknown Gear → Model Mismatch & Recovery chain legible as one read-only
experiment review station.

This is an orchestration and navigation layer over **existing deterministic
simulation models**. It is not a new physical experiment or a new discovery.

## Shared provenance and causality

The core scenario selects one simulated oracle eccentricity and one noise
bound, quantization, and seed. The Unknown Gear and Model Recovery phases use
identical settings and the discovery loop refuses to run if the exact
training observation sequence is not replayed across both modules.

The adaptive observer's first probe is drawn from the declared eight-profile
catalog and is explicitly a *catalog planner*, not evidence of the true oracle.
The geometry view compares ideal circular and elliptical pitch motion to expose
endpoint-vs-history observability.

A proposal is only created if the earlier model mismatch gate permits it.
The recovery module freezes a training-only hypothesis and checks disjoint
synthetic holdout angles. Its quarantined candidate cannot be promoted by the UI.

## Contract

Receipts include schema, origin SIMULATED, authority DEMONSTRATION_ONLY,
settings, observer plan, model rejection, source replay check, proposal,
held-out falsification, and unconditional no-promotion review gate.

No claim of calibrated noise, novel quantum mechanics, physical residue,
statistical confidence, or real-world device qualification is implied.
Existing frozen AH and NBG governance receipts are never modified.

Acceptance: npm run test:discovery-loop, npm test, npm run build.
