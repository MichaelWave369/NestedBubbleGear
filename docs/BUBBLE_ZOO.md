# Bubble Zoo

The **Bubble Zoo** is a collection of tiny canonical systems, each designed to demonstrate one behavior cleanly.

The rule is simple: one cage, one trick.

## Zoo-01 — Hidden Twin

Two full states share the same current observation but diverge under a later frozen probe.

Demonstrates:
- observational equivalence;
- behavioral inequivalence;
- Altermath revelation depth.

## Zoo-02 — Boundary Courier

Hidden parent state crosses an explicit interface as latent daughter-side residue.

Demonstrates:
- encoding;
- transfer;
- erasure control;
- ancestry receipt.

Related rung: AH3.

## Zoo-03 — Order Matters

Two paths use the same interface inventory in different order.

[
AB
eq BA.
]

Demonstrates:
- noncommuting transport;
- path memory;
- same ingredients / different computation.

Related rung: AH5.

## Zoo-04 — Closed But Changed

A closed declared-observable loop returns to the same coarse state while leaving nonzero full-state residue.

[
pi(Lx)=pi(x),qquad Lx
eq x.
]

Related rung: AH6.

## Zoo-05 — Clockwise / Counterclockwise

Opposite loop orientations remain identical under a coarse observer but leave different residues and cancel under inverse composition.

Related rung: AH7.

## Zoo-06 — Two Plaquettes

Two neighboring local loops are nontrivial while the full outer boundary is exactly trivial.

Demonstrates:
- local nontriviality;
- global cancellation;
- shared-edge inverse traversal.

Related rung: AH8.

## Zoo-07 — Active Zero

Two networks have the same steady node state.

One has zero current.

The other has nonzero cycle current satisfying zero net accumulation.

Demonstrates:
- equilibrium vs nonequilibrium steady state;
- hidden flux;
- active Altermath zero.

Planned branch: ALTM-F.

## Zoo-08 — False Dashboard

Visible output is stable while hidden state drifts or cycles outside the declared regime.

Demonstrates:
- Keyhole failure;
- observable-only false convergence;
- need for typed convergence receipts.

Related project: Φ-System 2.0.

## Zoo-09 — Conveyor Memory

The present symbol is identical, but the path operator differs because the route taken was different.

Demonstrates:
- information stored in transformation order;
- path as memory;
- symbolic conveyor semantics.

## Acceptance philosophy

Every Zoo model should eventually have:
- a minimal state definition;
- one primary witness;
- at least one negative control;
- exact or bounded expected results;
- a tiny executable harness;
- a claim firewall.

The Zoo is pedagogical infrastructure. Results become research evidence only when tied to frozen protocols and reproducible packages.
