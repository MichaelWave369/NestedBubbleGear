# NBG M1 v0.1.0 — Spec-Driven Independent Reproduction

M1 begins the post-AH meta-qualification phase.

This package implements four flagship results from their published frozen specifications and result contracts, without importing the original AH experiment modules:

- AH20 — capability/policy cut-set duality and toy reliability;
- AH35 — prerequisite-aware upgrade access structure and minimal blockers;
- AH42 — control-domain certification and refusal under incomplete evidence;
- AH44 — certificate/event revocation timing and provenance.

The implementation is intentionally structurally different from the original AH scripts. It does not reproduce historical formatting or internal receipt bytes. It independently derives the same selected public finite-model conclusions from the frozen contracts.

M1 is an implementation-independence test, not external replication by an unaffiliated researcher.
