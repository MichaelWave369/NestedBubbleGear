# NBG-AH12 v0.1.0 — Task-Dependent Memory

AH11 found a compressed residue that is sufficient for one declared future task: reconstructing the global outer operator.

AH12 asks whether that same memory remains sufficient when the future is allowed to ask different questions.

The experiment reuses the same 48 frozen path histories and evaluates memory descriptors against several query sets.

Core notation:

[
R_{\mathcal Q}(\Gamma)
]

where \(\mathcal Q\) is the permitted future-query family.

The central claim is intentionally narrow:

> In this finite ensemble and preregistered descriptor family, the coarsest sufficient memory depends on the future query set.

This is a toy model of task-relative memory, not a universal law of cognition or physical memory.
