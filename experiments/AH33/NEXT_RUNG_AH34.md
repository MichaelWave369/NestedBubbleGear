# AH34 Candidate — Mixed Task Profiles and Authority-Aware Privacy Budgets

AH33 varies one global task richness level at a time.

Real role systems are mixed: one actor may need full status while another only needs a binary risk signal.

AH34 should enumerate mixed per-grant or per-role task requirements and synthesize the least-disclosing release design for each.

Candidate questions:

1. Which role's task upgrade consumes the most coalition privacy?
2. Are there asymmetric task profiles where one FULL_STATUS grant remains safe?
3. What are the minimal task upgrades that collapse residual privacy to zero?
4. Can task upgrades be represented as a finite access structure over "extra distinctions"?
5. Can a declared privacy floor, for example:
   \[
   H(M\mid Z)\ge\epsilon,
   \]
   be enforced while maximizing weighted task richness?

This would turn AH33's three-point global frontier into a heterogeneous task-allocation and privacy-budget problem.
