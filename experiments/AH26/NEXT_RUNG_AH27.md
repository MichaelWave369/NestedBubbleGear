# AH27 Candidate — Windowed Evidence, Regime Change, and Cumulative Memory

AH26 uses cumulative evidence only.

That creates a known tension: old observations can dominate a changing failure regime.

AH27 should compare:

1. cumulative evidence;
2. rolling-window evidence;
3. exponentially discounted evidence.

Candidate questions:

- Can a real regime change be detected faster with bounded-memory evidence?
- When does a short window become too noisy?
- Can cumulative memory remain compatible with independence while a recent window shows common-mode coupling, or vice versa?
- How should the Reality Ledger preserve long-horizon provenance and recent hazard evidence without pretending they answer the same query?

This reconnects sequential auditing to task-indexed memory: the appropriate evidence summary can depend on the time horizon of the governance question.
