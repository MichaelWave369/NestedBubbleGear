# NBG-RB2 — Corpus Freeze

RB2 freezes the first literature corpus and extraction contract for the Resonant Bubbles line.

Artifacts:

- `CORPUS_FREEZE.md` — eligibility, exclusion, lineage, fold and no-rerun rules
- `corpus_manifest.json` — 14 primary experimental records / 11 lineages
- `context_registry.json` — planarian bioelectric, DNA-antenna debate and reviews; explicitly not model input
- `extraction_schema.json` — row-level normalization and anti-leakage contract

**No RB2 file is a treatment protocol and no RB3 model has been executed.**
