# AH33 Candidate — Task Richness versus Coalition Privacy Frontier

AH32 succeeds because the frozen actor tasks require only the binary question:

> Is this horizon showing common-mode evidence?

The selected release hides the lifetime distinction between `INDEPENDENCE_COMPATIBLE` and `INSUFFICIENT_EVIDENCE`.

AH33 should vary task richness.

Candidate task levels:

1. `COMMON_ONLY`
2. `COMMON_VS_UNKNOWN`
3. `FULL_STATUS`

For each task profile, synthesize least-disclosing per-role releases and measure:

- actor task error;
- release entropy;
- grand-coalition residual entropy about `Q_MULTI`;
- whether coalition-safe release remains feasible.

Core question:

```text
How much task fidelity can be retained before the denied target becomes reconstructible again?
```

This would expose an explicit utility/privacy frontier instead of treating task sufficiency as one fixed contract.
