# NBG-AH23 v0.1.0 — Robust Pareto Frontiers Under Failure-Rate Uncertainty

AH22 evaluated policy tradeoffs at one diagnostic failure probability.

AH23 evaluates the same legal policy families over the frozen finite uncertainty set:

[
\mathcal P=\{0.05,0.10,0.15,0.20,0.25,0.30\}.
]

Each policy is measured by worst-case reliability and maximum regret relative to mathematical capability, while keeping authorization cost and policy-induced singleton failures explicit.

The main result is deliberately conservative: under the common identical-failure model, the AH22 Pareto frontier membership remains unchanged across the declared scenarios.

That negative result motivates AH24, where Keyholes receive heterogeneous and correlated failure regimes.
