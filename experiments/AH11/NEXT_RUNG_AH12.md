# AH12 Candidate — Adaptive Memory Under Changing Tasks

AH11 identifies a task-specific compressed connector residue that is sufficient for one declared global reconstruction target.

The next question should not assume the task remains fixed.

## Candidate experiment

Use the same underlying path ensemble, but define multiple future tasks:

1. reconstruct the global outer operator;
2. reconstruct the intermediate transported loop (H_2^{(0)});
3. reconstruct the cumulative transport (P_2);
4. answer a later probe that depends on one of those intermediate quantities.

Then ask whether the AH11 residue

[
R_\Gamma=H_3^{(0)}H_2^{(0)}
]

remains sufficient across tasks.

Expected conceptual outcome:

- a residue can be minimal for one task;
- the same compression can be lossy for another;
- "memory sufficiency" must therefore be indexed by the allowed future query set.

Target notation:

[
R_{\mathcal Q}(\Gamma)
]

where (\mathcal Q) is the declared family of future probes.

This would connect NBG path memory directly to behavioral equivalence and the Keyhole framework.
