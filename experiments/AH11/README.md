# NBG-AH11 v0.1.0 — Path Compression and Minimal Connector Memory

AH10 established that full connector history is sufficient to reconstruct a three-plaquette outer operator.

AH11 asks the next question:

> How much of that path history must actually be retained?

The frozen experiment compares several candidate memory descriptors over 48 labeled path histories.

The key result is that the task-specific residue

[
R_\Gamma = H_3^{(0)}H_2^{(0)}
]

is sufficient to reconstruct the global operator

[
G_\partial = R_\Gamma H_1,
]

while a descriptor with the same number of classes and the same Shannon entropy,

[
P_2=T_1T_2,
]

is **not** sufficient.

So compression quality depends on preserving the right causal distinctions, not merely on retaining the same number of bits/classes.

This is a finite matrix toy model, not a claim about physical memory, spacetime, or cosmology.
